# Firedoor v0.9 — Slice 9A: Synthetic boundary-regression contract

**Base:** `9d6b0b8` (`main`, v0.8 README merged). **Branch:** `feat/v09-regression`.
**Purpose:** Start v0.9 safely, with a reproducible, fail-closed synthetic CI contract.

## What's implemented

- `internal/regression` implements strictly bounded, duplicate-key-rejecting JSON validation and deterministic interpretation for one **synthetic** hardened `edge-to-data` HTTP/TCP:8080 observation. The expected observation is hardcoded to `unreachable`; input cannot silently change it.
- Three bundled and explicitly labeled synthetic fixtures (`intact`, `weakened`, `missing`) exercise `MATCH`, `REGRESSION`, and `INCONCLUSIVE`.
- The CLI `go run ./scripts/v09/cmd/fixturegate --fixture intact|weakened|missing` returns success **only** for `MATCH`. Both weakened and missing cases fail as expected.
- A dedicated GitHub Actions job runs the focused unit tests plus the positive/negative gate. Repository Go, Terraform and React quality lanes remain in place and unchanged.
- `scripts/v09/Test-FiredoorV09Slice9A.ps1` checks Go formatting/tests/vet/modules, Terraform formatting and React typechecking/tests/build **without running live tools**.

## Important limitations

This is an evaluator **contract test**, not an infrastructure regression test. The synthetic observations are not generated by live network traffic, and the `MATCH` verdict is **not** verified Kubernetes NetworkPolicy enforcement. An unreachable connection does not independently establish which policy, CNI or failure caused it. The dedicated v0.9 workflow must not be marketed as a real-cluster security check until the later integration work passes its own gates.

The 9A CLI does not accept user-supplied filenames, URLs, kubeconfigs, arbitrary endpoint addresses, local evidence, or Terraform state. It contains no cluster-mutating operations, Docker, kubectl, Terraform apply/destroy/test or untrusted PR secrets.

## Acceptance on Windows PowerShell 5.1

Run from `feat/v09-regression` with dependencies already installed (`go mod download`, `npm ci` when required):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\v09\Test-FiredoorV09Slice9A.ps1
```

Manual positive/negative demonstration:

```powershell
go run ./scripts/v09/cmd/fixturegate --fixture intact      # MATCH, exit 0
go run ./scripts/v09/cmd/fixturegate --fixture weakened    # REGRESSION, nonzero
go run ./scripts/v09/cmd/fixturegate --fixture missing     # INCONCLUSIVE, nonzero
```

Review GitHub Actions for the proposed PR before merging. In particular, verify the new focused `v09 synthetic boundary contract` job and existing project jobs are green. No CI success is claimed before a real run completes.
